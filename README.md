
# Personal Portfolio (v1)

An early personal portfolio site built with vanilla HTML, CSS, and JavaScript — my first project putting frontend fundamentals into practice.

## Features
- Responsive navigation with anchor-linked sections (Home, About, Skills, Contact)
- Dark mode toggle built with plain JavaScript DOM manipulation
- Sections for introduction, background, skills, education, and contact links

## Tech Stack
- HTML5
- CSS3 (Flexbox, custom animations)
- JavaScript (DOM manipulation, event handling)

## What I Learned
This project was my first hands-on practice with structuring a multi-section site, styling with Flexbox, and adding basic interactivity (the dark mode toggle) using vanilla JavaScript. It laid the foundation for the more advanced projects in my other repositories.
